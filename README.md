# Senai-Blog-Next

Blog — Next.js

## Descrição

Aplicação web de blog desenvolvida com Next.js, demonstrando App Router, rotas baseadas em arquivos e renderização no servidor.

## Tecnologias

- Next.js
- React
- JavaScript

## Conceitos aplicados (Aula 03)

- App Router
- Rotas baseadas em arquivos
- Renderização no servidor (SSR)
- Componentes React

## Como executar

Abra o arquivo `index.html` em qualquer navegador moderno.
